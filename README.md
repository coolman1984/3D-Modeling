# 🧭 منصة تخطيط المساحات

منصة تساعد العميل يجرّب ترتيب المكان، ويعرف هل الأشياء هتدخل وتشتغل فيه، قبل ما يصرف على التنفيذ.

## 📚 الوثائق

| الملف | المحتوى |
|---|---|
| [`docs/01-master-plan.md`](docs/01-master-plan.md) | الخطة الرئيسية الكاملة: الرؤية والمعمارية والأسواق والمراحل (الوجهة البعيدة) |
| [`docs/02-core-plan.md`](docs/02-core-plan.md) | خطة النواة الصافية: أول حاجة هنبنيها، خطوة خطوة |
| [`docs/decisions/`](docs/decisions/) | سجل القرارات المعمارية وأي اختلاف عن الخطة |
| [`CLAUDE.md`](CLAUDE.md) | دليل العمل لوكلاء البرمجة |

## 🚦 الحالة الحالية

**النواة الصافية خلصت** 🎉 (المراحل ج٠ ← ج٧)

| المرحلة | الحالة |
|---|---|
| ج٠ — التجهيز | ✅ |
| ج١ — الوحدات | ✅ |
| ج٢ — الهندسة | ✅ |
| ج٣ — النموذج | ✅ |
| ج٤ — الأوامر والتراجع | ✅ |
| ج٥ — الفحوص | ✅ |
| ج٦ — الأرقام | ✅ |
| ج٧ — الحفظ والفتح | ✅ |
| ت١ — محرر ثنائي في المتصفح | ✅ |
| ت٢ — عرض مجسم خفيف، أو ت٣ — حزمة القاعات | ⏳ التالية |

## 🛠️ التشغيل

```bash
pnpm install
pnpm dev        # يفتح المحرر على http://localhost:5173
pnpm check      # فحص الأنواع + كل الاختبارات + اختبار المتصفح
```
