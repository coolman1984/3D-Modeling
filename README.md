# 🧭 مخطط المساحات

برنامج بيساعدك تجرّب ترتيب أي مكان، وتعرف هل الحاجات هتدخل وتشتغل فيه، قبل ما تصرف على التنفيذ.

## ▶️ التشغيل بضغطة واحدة

1. ثبّت **Node.js** إصدار LTS من [nodejs.org](https://nodejs.org) (مرة واحدة بس).
2. افتح فولدر المشروع واضغط دبل كليك على:
   - **ويندوز:** `start.bat`
   - **ماك:** `start.command`
   - **لينكس:** `./start.sh`
3. أول مرة بيثبّت ويجهّز لوحده (دقيقتين تقريبًا)، وبعدين المتصفح بيفتح على البرنامج.

البيانات كلها بتتحفظ على جهازك في فولدر `data`.

## ✨ البرنامج بيعمل إيه

- 📁 **مشاريع كتير**: تعمل وتنسخ وتمسح، وكل مشروع محفوظ في قاعدة بيانات.
- 🏛️ **القاعة**: المقاسات والسقف والأبواب على أي حيطة والأعمدة.
- 🪑 **الأصناف**: تعمل أي صنف بمقاساته ومساحة استخدامه وعدد كراسيه وشكله المجسم.
- ✋ **التصميم بإيدك**: تسحب وتلف وتمسح، والمشاكل والأرقام بتظهر لحظيًا.
- 🏠 **عرض مجسم** للعميل، وتقدر تحفظه صورة.
- 🕘 **سجل كامل**: كل تعديل مين عمله وإمتى، وترجع لأي نسخة.
- 🤖 **وكيل ذكي**: تكتب المطلوب، و Claude Code أو Codex أو أي خدمة بمفتاح يصمم بنفسه وإنت شايف.
